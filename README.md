
🌱 Idea de proyecto

AgriTech Eterazama sería una plataforma web para la venta y gestión de productos agrícolas, donde los productores puedan consultar productos, precios y disponibilidad, realizar pedidos y llevar un registro de sus compras.

La plataforma podría comercializar:

🛠️ Herramientas y equipos agrícolas, como mufladoras/fumigadoras y otros implementos.
🧪 Fungicidas.
🌱 Fertilizantes y abonos.
🪨 Cal agrícola.
🌾 Otros insumos utilizados por los productores de Eterazama.
📦 Productos agrícolas adicionales que posteriormente se incorporen al catálogo.
🎯 Problema que busca solucionar

Actualmente, los productores pueden tener dificultades para conocer qué productos agrícolas están disponibles, consultar precios, verificar existencias y realizar sus compras de manera rápida y organizada. Además, para el vendedor, llevar manualmente el registro de productos, ventas, clientes e inventario puede generar desorganización y pérdida de información.

💡 Propuesta de solución

Crear un sistema de venta de productos agrícolas para Eterazama, que permita al administrador registrar y controlar:

Productos → Categorías → Precios → Stock → Clientes → Pedidos → Ventas

Mientras que el cliente podrá:

Ingresar al sistema.
Consultar el catálogo.
Ver precios y disponibilidad.
Agregar productos a un carrito.
Realizar un pedido.
Consultar el estado de su pedido.
Revisar su historial de compras.
🎯 Objetivo

Desarrollar una plataforma web para la venta sostenible de insumos, herramientas y productos agrícolas en Eterazama, facilitando el acceso de los productores a los productos, optimizando la gestión de inventario y mejorando el proceso de ventas.
